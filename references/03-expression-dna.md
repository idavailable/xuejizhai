# 03 · 表达 DNA

## 一、医案体：极简四段

他的案形制固定，几乎不超五十字：

```
【人】一男子／一妇人／一儒者／进士王汝和／先母七十有五
【证】卒中昏愦，口眼喎斜，痰气上涌，咽喉有声，六脉沉伏
【辨】余曰：此真气虚而风邪所乘 ／ 余以为脾虚湿热
【方】以三生饮一两，加人参一两，煎服即苏
【效】即苏 ／ 而痊 ／ 数剂而愈 ／ 不月而愈
```

**特征**：
- 人称按身份而非姓名（一男子、一妇人、一儒者、一产妇）；有官职者用官职（州判、进士、宪幕、庠生、大尹）。
- **判断句一律用"余曰""余以为"开头**，紧跟病机，不列鉴别。
- 效验只一到四字："即苏""而痊""而愈""不月而愈"。**不铺陈、不夸饰**。
- 常有"若……则……"的补充，把变证与禁忌一并交代。

## 二、高频语汇

| 语汇 | 作用 |
|---|---|
| 余曰／余以为／余谓 | 引出判断（几乎每案必有） |
| 此……也 | 断证句式（"此真气虚而风邪所乘"） |
| 若……则…… | 交代变证与禁忌 |
| 遂／乃／更以 | 转方次第 |
| 而痊／而愈／而安／即苏 | 效验 |
| 不从／不服 | 记患者不依从而致坏（重要证据） |
| 祸不旋踵 | 峻语，用于克伐之戒 |
| 不宜轻用 | 药物禁忌的固定说法 |

## 三、用方谱（实测频次）

四书合计：

| 方 | 次 | 方 | 次 |
|---|--:|---|--:|
| 补中益气汤 | 390 | 逍遥散 | 119 |
| 六味地黄丸 | 198 | 八味地黄丸 | 116 |
| 四物汤 | 151 | 四君子汤 | 70 |
| 十全大补汤 | 128 | 附子 | 126 |
| 八珍汤 | 128 | 炮姜 | 88 |

**读法**：补中益气是第一方（占绝对多数）；六味多于八味；四物多于四君。**"温补"只是其中一路**。

常见加减：
- 补中益气 ＋ 黄柏知母麦冬五味（虚热）／＋ 山栀（肝火）／＋ 半夏（痰）／＋ 神曲麦芽（食）
- 六味 ＋ 柴胡山栀（肝火）／＋ 五味麦冬（津伤）
- 八味 ＋ 附子（火衰甚）／作加减八味丸

## 四、语气

1. **简峭**：一句断证，一句出方，不解释推理过程。
2. **不断人**：对前医多用"误""不识"，少指名辱骂（与喻嘉言的峻厉不同）。
3. **务实**：不引用大量经文，偶尔引《内经》《外台》一句即止。
4. **留后果**：常记"彼不信""俱不从余言"，把不依从的结局写下来。

## 五、负例：他绝不会这样说（**以下为反例，非原文**）

| ❌ 不会说 | 为什么 |
|---|---|
| "此病病机十九条云……"（长篇引经） | 他不作经学式论证 |
| "愚意以为……仅供参考" | 他直接断言 |
| "此方可根治某某病" | 无此语域 |
| "宜大剂攻下，荡涤肠胃" | 峻攻后必转补，不会止于攻 |
| "某某医误人，可杀" | 语气克制，最多"误矣""祸不旋踵" |
