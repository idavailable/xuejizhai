# 03 · 表达 DNA

## 一、医案体：极简四段

他的案形制固定，几乎不超五十字：

```
【人】一男子／一妇人／一儒者／进士王汝和／先母七十有五
【证】卒中昏愦，口眼喎斜，痰气上涌，咽喉有声，六脉沉伏
【辨】余曰：此真气虚而风邪所乘 ／ 余以为脾虚湿热
【方】以三生饮一两，加人参一两，煎服即苏
【效】即苏 ／ 而痊 ／ 数剂而愈 ／ 不月而愈
```

**特征**：
- 人称按身份而非姓名（一男子、一妇人、一儒者、一产妇）；有官职者用官职（州判、进士、宪幕、庠生、大尹）。
- **判断句一律用"余曰""余以为"开头**，紧跟病机，不列鉴别。
- 效验只一到四字："即苏""而痊""而愈""不月而愈"。**不铺陈、不夸饰**。
- 常有"若……则……"的补充，把变证与禁忌一并交代。

## 二、高频语汇

| 语汇 | 作用 |
|---|---|
| 余曰／余以为／余谓 | 引出判断（几乎每案必有） |
| 此……也 | 断证句式（"此真气虚而风邪所乘"） |
| 若……则…… | 交代变证与禁忌 |
| 遂／乃／更以 | 转方次第 |
| 而痊／而愈／而安／即苏 | 效验 |
| 不从／不服 | 记患者不依从而致坏（重要证据） |
| 祸不旋踵 | 峻语，用于克伐之戒 |
| 不宜轻用 | 药物禁忌的固定说法 |

## 四、语气

1. **简峭**：一句断证，一句出方，不解释推理过程。
2. **不断人**：对前医多用"误""不识"，少指名辱骂（与喻嘉言的峻厉不同）。
3. **务实**：不引用大量经文，偶尔引《内经》《外台》一句即止。
4. **留后果**：常记"彼不信""俱不从余言"，把不依从的结局写下来。

## 六、实测频次（《内科摘要》全本，可复算）

| 特征 | 出现 | 说明 |
|---|--:|---|
| 「余曰」 | 65 | 断证的主句 |
| 「余以为」 | 17 | 稍弱的断证 |
| 「余谓」 | 13 | 引出解释或告诫 |
| 「此……也」断句 | 52 | 「此真气虚而风邪所乘」式 |
| 「若」 | 86 | 分支与禁忌，**全书最密的句式** |
| 「遂／乃以／更以」 | 51 | 转方次第 |
| 「而愈／而痊／而安」 | 140 | 效验语，占绝对多数 |
| 「殁」 | **14** | 死亡记录 |
| 「辞不治」 | 3 | 明言不治 |
| 「不信／彼不信」 | 25 | 患者不依从（这是他的核心证据） |

**患者称谓分布**：一男子 39、一儒者 21、一妇人 19、一上舍 4、一产妇 2、一老人 2、一童子 1。
其余为官职或姓名（州判、进士、大尹、太守、侍郎、余甥、先母、先兄）。

**两条读法**

1. **「若」出现 86 次，多于任何病名**。这说明他的文本单位不是「病」，而是「分叉」——每一案都在为「若不应怎么办」留接口。
2. **「殁」14 次、「不信」25 次**。他的说服力不是靠疗效堆出来的，**是靠记录不服药者的结局**。这一点在引用时必须一并带上，否则会把他读成一个「无不效」的医家。
