# 01 · 核心心智模型

> 引用体例：`「」` 内为原文，标点照电子本。可用 `scripts/check_quotes.py` 复核。

## 第一层：脾胃为五脏根本

> 「夫人以脾胃为主，未有脾胃实而患疟痢者，若专主发表攻里，降火导痰，是治其末而忘其本。」

这句话的真正力量在它后面那一串推论——**"本"不是口号，是处方约束**：

> 「盖胃为五脏之根本，故黄柏、知母不宜轻用，恐复伤胃气也。」

从"脾胃为本"直接推出"苦寒药不宜轻用"，并**指名黄柏、知母**。这是他全部处方倾向的源头。

## 第二层：虚有定位，补有层次

他不说"虚则补之"，而是先定位：

| 虚在何处 | 补法 | 依据 |
|---|---|---|
| 中气下陷、四肢倦怠、发热 | 补中益气（升阳） | 承李东垣 |
| 脾土虚弱、痰食不运 | 六君、四君 | 脾胃为本 |
| 阴血亏耗、夜热盗汗 | 六味地黄 | 滋水涵木 |
| 命门火衰、畏寒足冷 | 八味、加减八味 | 水中补火 |
| 气血两虚 | 八珍、十全大补 | 双补 |

**关键**：这五层不是并列可选，而是**按"哪一路最急"排序**。他的医案里常见"先……后……"的次第语。

## 第三层：朝夕分补——一天内治两条线

三条原文（同一书）：

> 「余朝用补中益气加黄柏、知母、麦门、五味煎送地黄丸，晚用地黄丸料加黄柏、知母数剂，诸症悉退。」
> 「朝用六味地黄丸以滋养肝木，夕用六君加当归、芍药以调补脾土，不月而愈。」
> 「余朝用四君为主，佐以熟地、当归，夕用加减八味丸，更以附子唾津调搽涌泉穴，渐愈。」

三例三种配法：**朝补气晚滋阴／朝滋阴晚补脾／朝补气晚温阳**。

→ **"朝夕分补"是一种时间结构，不是一组固定方**。早晨主升发、主气、主脾；傍晚主收藏、主阴、主肾。哪条线更急就先放在早晨。说成"早补中益气晚六味"是把它僵化了。

## 第四层：外科、伤科从内治

《正体类要》"正体主治大法"是全书最集中的证据：讲跌扑损伤，结论全是内科。

> 「若行克伐，则虚者益虚，滞者益滞，祸不旋踵矣。」

逐条内治路径（原书体例，每条一证一方）：

| 证 | 判 | 方 |
|---|---|---|
| 胁肋胀痛、喘咳吐痰、大便通和 | 肝火侮肺 | 小柴胡加青皮、山栀 |
| 胸腹胀痛、大便不通、喘咳吐血 | 瘀血停滞 | 当归导滞散 |
| 既下而痛不止、按之仍痛 | 瘀血未尽 | 加味四物汤「补而行之」 |
| 腹痛按之不痛 | 血气伤 | 四物加参、术 |
| 下而胸胁反痛 | 肝血伤 | 四君加芎、归 |
| 肌肉间作痛 | 营卫气滞 | 复元通气散 |
| 筋骨作痛 | 肝肾气伤 | 六味地黄丸 |
| 内伤下血作痛 | 脾胃气虚 | 补中益气汤 |
| 外伤出血作痛 | 脾肺气虚 | 八珍汤 |

**规律**：同是"痛"，按"按之痛与不痛""下后痛止与不止""痛在肌在筋在腹"分流，且**分流后全部指向补**。

## 第五层：善用成方，贡献在次序

四书用方清单几乎全是前人方：补中益气、六味、八味、四君、四物、八珍、十全大补、逍遥、归脾、小柴胡、当归导滞、复元通气。

他不自制方，贡献在**加减与配次**：
- 同一方在不同证下加不同药（补中益气加黄柏知母麦冬五味／加山栀／加半夏）；
- 同一病在不同阶段换方（先攻后补、先清后补）；
- 早晚分工（朝夕分补）。

## 内在张力（三组）

### 张力一：极重脾胃 ↔ 大量使用滋阴

- A 面：「胃为五脏之根本，故黄柏、知母不宜轻用。」
- B 面：六味地黄 198 次，为第二大方；且常与补中益气同用。
- **读法**：他反的是"苦寒直折"，不是"滋阴"。六味是甘平滋填，与黄柏知母苦寒不同层。这一点若不分清，会把他读成"排斥一切寒凉"。

### 张力二：被讥"执泥补法" ↔ 医案中有大量攻下

- A 面：外科枢要序记时人语——「人多訾先生，以为执泥补法，不知合变」。
- B 面：正体类要有"用加味承气汤下之"，外科有"刺去其脓"，内科有"用大黄"之类。
- **读法**：他不是不攻，是**攻后必转补**（「既下而痛不止……用加味四物汤补而行之」）。"执泥"之讥只看到了后半段。

### 张力三：医案极简 ↔ 判断极快

- A 面：一案常只三四十字：患者身份＋证＋脉＋一句辨＋方＋效。
- B 面：结论下得极快，几乎不列鉴别过程。
- **读法**：**简不是浅，是他把鉴别压缩进了"一句辨"**。读他的案，价值在那半句"余以为……"，后半段的方反而是套用的。
