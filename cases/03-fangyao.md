## 一、核心十二方（按用例数排）

### 1. 补中益气汤（全书第一方，出现 390 处）

他称此方治「元气亏损」诸症的总方。原文在卷上症二末与症十末两次给出适应范围：

> 「皆是无根虚火，但服前汤固其根本，诸症自息，若攻其风热则误矣。」

- **他的用法**：几乎全部加减使用，常见加味为麦门冬、五味子（保肺生津）、炮姜（虚寒）、茯苓半夏（痰）、山栀（肝火）、黄柏知母（下焦湿热）、附子（阳虚）。
- **剂量实例（照录）**：`内参、〔芪〕、归、术各加三钱，甘草一钱五分，加炮姜、附子各一钱`；`倍用参、〔芪〕、归、术、甘草`；`倍加参、〔芪〕`。
- **禁忌线**：脉「洪大按之如无」时可用；若认作实火而用苦寒，则成坏病（见卷上症二徐克明案）。

### 2. 六味丸（一名地黄丸，一名肾气丸）

> 「治肾经不足，发热作渴，小便淋秘，气壅痰嗽，头目眩晕，眼花耳聋，咽燥舌痛，齿牙不固，腰腿痿软，自汗盗汗，便血诸血失音，水泛为痰，血虚发热等症。其功不能尽述。」

- 组成：熟地黄（八两，杵膏）山茱萸肉／干山药（各四两）牡丹皮／白茯苓／泽泻（各三两），炼蜜丸，每服七八十丸，空心食前滚汤下。
- **他引仲景语为据**：「气虚有饮，用肾气丸补而逐之」——注意他把仲景「肾气丸」等同六味，这是他的读法，非通行本义，引用时须标是他的解释。

### 3. 八味丸

> 「治命门火衰，不能生土，以致脾胃虚寒，饮食少思，大便不实，脐腹疼痛，夜多漩溺等症。」

- 即六味丸加肉桂、附子各一两。
- **他是这样推的**：脾胃久治不效 → 补土之母 → 命门火。这条推理由患者朱佐的记述保存得最完整：「此非脾胃病，乃命门火衰不能生土」。

### 4. 加减八味丸

> 「治肾水不足，虚火上炎，发热作渴，口舌生疮，或牙龈溃烂，咽喉作痛；或形体憔悴，寝汗，发热，五脏齐损。」

- 即六味丸加肉桂一两。
- **与八味丸的分界**：八味治「火衰不能生土」（虚寒），加减八味治"水不足而火上炎"（虚火）。同是桂附，一为温阳一为引火归原，不可混。

### 5. 十全大补汤

> 「此皆是无根虚火，但服此药，诸症悉退。」

- 即八珍加黄〔芪〕、肉桂。用于"虚损已深、气血俱亏"的收尾阶段；书中多作「百余剂」长服（见卷上症四「彼计服过人参一十三斤，姜、附各斤余」）。

### 6. 四君子汤 / 六君子汤 / 香砂六君子汤 / 异功散

- 四君：`人参白术茯苓（各二钱）甘草（炙，一钱）`
- 六君：四君加半夏、陈皮。**关键一句**：

> 「若见内热，或饮食难化作酸，乃属虚火，须加炮姜。其功甚速。」

这条注解是全书最能体现他风格的一处——**见「内热／作酸」不加清热药，加炮姜**。

### 7. 四物汤 / 加味四物汤

- 四物：`当归熟地黄（各三钱）芍药（二钱）川芎（一钱五分）`
- 他给四路分流：脾虚不能生血→四君；脾郁→归脾；肾水涸不能生肝血→六味。

### 8. 归脾汤 / 加味归脾汤

> 「治思虑伤脾，不能摄血，致血妄行。」

- 加味即加柴胡、山栀。用于「郁结伤脾」一路（卷上症一妇人喉核案、卷下便秘儒者案）。

### 9. 逍遥散 / 加味逍遥散

> 「治肝脾血虚发热，或潮热，晡热，或自汗盗汗……或月经不调，肚腹作痛。」

- 加味即加牡丹皮、山栀。**这是他处理「怒」的专用方**：因怒致病者，多数案以加味逍遥散收束。

### 10. 人参养荣汤

> 「若气血虚而变见诸症，莫能名状，勿论其病，勿论其脉，但用此汤，其病悉退。」

「勿论其病，勿论其脉」六字在全书里只出现这一次——是他对自己「守方」最极端的表述，引用时须连上下文（前提是「气血虚而变见诸症」）。

### 11. 独参汤

> 「治一切失血，恶寒发热，作渴烦躁。盖血生于气，故血脱补气，阳生阴长之理也。」

- `人参（二两）枣十枚`。书中用于大失血后（花蕊石散之后）与误下之后救逆。

### 12. 人参理中汤 / 附子理中汤

- 理中：`人参白术干姜（炮）甘草（炙）各等分，每服五、七钱，或一两`
- 加附子即附子理中，「治中气虚寒而患前症，又治入房腹痛，手足逆冷，或犯寒气，或食冷物」。

## 二、脾胃虚寒线（晨泻、五更泻专用）

| 方 | 主治（原文） | 组成要点 |
|---|---|---|
| 二神丸 | 「脾肾虚弱，侵晨五更作泻，或全不思食，或食而不化，大便不实，神效」 | 破故纸四两、肉豆蔻二两，红枣四十九枚、生姜四两煮枣为丸 |
| 五味子散 | 「肾泄，在侵晨五更泻，饮食不进」 | 五味子（炒）二两、吴茱萸（炒）五钱，每服二钱 |
| 四神丸 | 「脾肾虚弱，大便不实，饮食不思」 | 肉豆蔻、补骨脂、五味子、吴茱萸 + 姜枣 |
| 益黄散 | 「脾土虚寒，寒水反来侮土，而呕吐不食」 | 陈皮一两，青皮、诃子肉、甘草、丁香各二钱 |

**分界**：五更泻先用二神／四神；不应则补其母（八味丸）；若「脾气郁滞」则改二陈加桔梗山栀送香连丸——他在卷上症八给出这条分叉。

## 三、他并不废攻（此节最易被忽略）

后世讥他"执泥补法"，但书中攻法用得极准：

| 方 | 用在哪 | 原文要点 |
|---|---|---|
| 桃仁承气汤 | 中焦蓄血（王治中遍身发黄、妄言如狂、胸痛手不可近） | 「一剂，下瘀血而愈」 |
| 抵当汤 | 下部蓄血发狂（朱阳山弟） | 「而愈」 |
| 芍药汤 | 痢初起湿热壅滞 | 「如痢不减，加大黄」；崔司空加大黄二钱，汪天锡加大黄一两 |
| 三黄丸 | 「热痢腹痛……及一切实火症」 | 芩连柏等分 |
| 当归龙荟丸 | 「肝经实火，大便秘结，小便涩滞」 | 含大黄、芦荟、青黛、麝香 |
| 茵陈五苓散 | 酒积黄胆 | 李蒲汀「二剂而愈」 |
| 葛花解酲汤 | 酒积，上下分消 | 得微汗，酒病去 |
| 花蕊石散 | 吐紫血块 | 先花蕊石，后独参 |
| 猪胆汁导 | 燥在直肠 | 「若燥在直肠，用猪胆汁导之」 |

**他的攻法纪律**：攻之前必辨「形气病气俱不足」与否；攻之后必转补（见"攻下之后必转补"一条）。

## 四、他明确标了「忌」的方（这是反模式清单的原始出处）

| 方 | 他的评语 |
|---|---|
| 润肠丸 | 「若因失血，或因肾不足，当滋肾，**最忌此丸**」；「若燥在直肠，用猪胆汁导之，**亦忌前药**」 |
| 搜风顺气丸 | 儒者服后「胸膈不利，饮食善消，面带阳色」——成了伤阴之象 |
| 沉香化气丸 | 「盖化气之剂，峻厉猛烈，无经不伤，无脏不损，岂宜轻服？」 |
| 法制清气化痰丸 | 「彼为有验，修合馈送，**脾胃虚者，无不受害**」 |
| 愈风丹／天麻丸／搜风丸 | 用作「预防中风」时：「适所以招风取中也」 |
| 犀角地黄汤 | 用于脾虚吐血者，「气高而喘，前病益盛」 |
| 黄柏、知母 | 「不宜轻用，恐复伤胃气也」 |

**注意**：以上都是**有前提**的禁忌，不是绝对禁用。书中桃仁承气、抵当汤、大黄都用了——**他禁的是"无前提地用"，不是"用"**。这一层若读丢，就会把他读成一个只会温补的人。

## 五、煎服法里的四个特别处理

1. **冷服**：少宗伯顾东江「煎熟冷服之即睡」；州同韩用之「以水顿煎六碗，冰冷与饮」。原注：「此假热而治以假寒也」。
2. **热服取汗**：葛花解酲汤「得微汗，酒病去矣」；神效黄〔芪〕汤「临卧热服」。
3. **外治**：盐附子炒热熨脐腹；附子作饼贴脐；附子唾津调搽涌泉穴；贴腰脐及涌泉。
4. **含咽**：沈大雅之母案「以参、术、附子为末……丸如粟米大，入五七粒于口，随津液咽下」，二日后加至十余粒。
