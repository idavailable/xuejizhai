## 症一 · 脾肾亏损头眩痰气等症（8 案）

**主轴**：痰与眩，他归到"肾不能纳气归源"——**不是痰的问题**。并由此推出全书最著名的一句用药戒律。

> 「盖胃为五脏之根本，故黄柏、知母不宜轻用，恐复伤胃气也。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 阁老梁浓斋 | 气短有痰，小便赤涩，足跟作痛，尺脉浮大按之则涩 → 肾虚而痰饮 | 四物送六味丸 | 不月而康 |
| 都宪孟有涯 | 气短痰晕，服辛香之剂致痰盛遗尿，两尺浮大按之如无 → 肾不纳气，香燥致甚 | 八味丸料 | 三剂而愈 |
| 孙都宪 | 形体丰浓，劳神善怒，面赤口渴吐痰，头晕，左三脉洪而有力、右三脉洪而无力 → 足三阴亏损 | 补中益气加麦门、五味 + 加减八味丸 | 而愈 |
| 昌平守王天成 | 头晕恶寒，形体倦怠，得食稍愈，劳而益甚，寸关脉浮大 → 脾肺虚弱 | 补中益气加蔓荆子 → 补中益气汤 | 而愈 → 而痊 |
| 大尹祝支山 | 因怒头晕，拗内筋挛，寒热，日晡热甚 → 肝火筋挛，气虚头晕 | 八珍加柴胡、山栀、牡丹皮 | 二十余剂而愈 |
| 上舍顾桐石（问答） | 房劳过度患头晕吐痰，用清气化痰愈甚 | （问答中定「肾虚不能纳气归源」） | 治者不悟**而殁** |
| 一男子 | 素浓味，胸满痰盛 → 膏粱之人内多积热 | 法制清气化痰丸 | 而愈（原注：修合馈送，脾胃虚者无不受害） |
| 先兄 | 体貌丰伟，唾痰甚多，脉洪有力，遇风头晕欲仆，口舌破裂，误食姜蒜益甚 → 命门虚火不归源 | 八味丸及补中益气加附子钱许 | 即愈（停药月余复作） |

顾桐石那段问答里，他还辨了两个"同症不同命"的例子：孟有涯「专于益火补气」得生，陈东谷「专主攻痰行气」不救。

**本症所见规则**：#2 苦寒禁区｜#23 先辨「土母」

## 症二 · 肝肾亏损血燥结核等症（5 案，末案未见转归）

**主轴**：颈项结块，他不作痰核消散，而作**肝火血燥**——「滋肾水、生肝血」。

> 「此肝胆经血少而火燥也。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 儒者杨泽之 | 性躁嗜色，缺盆结一核 → 肝火血燥筋挛；误服降火化痰、外敷南星商陆，转大如碗 | 补中益气及六味地黄，间以芦荟丸 | 年余元气渐复而肿消 |
| 一男子 | 素善怒，左项微肿渐大如升，用清痰理气致大热作渴、小便频浊 → 肾水亏损 | 六味地黄、补中益气 | 而愈 |
| 一男子 | 颈间结核，大溃年余 | 清肝火、养肝血、益元气 | 而愈 |
| 一男子 | 眉间一核，初如豆粒，二年渐大如桃 | 同上 | 而愈 |
| 举人江节夫 | 颈、臂、胁肋各结一核，恪服祛痰降火软坚益甚，次年各核皆溃，脉浮大而涩 | （断「秋金将旺，肝木被克，必不起」） | 未见转归记录 |

**本症所见规则**：#24 治未病／断死期｜#31 疮疡内治

## 症三 · 脾肾亏损小便不利肚腹膨胀等症（9 案）

**主轴**：肿胀由小便不利而来，他最反对**淡渗**——「淡渗导损阳气，阴无以化」。

> 「此肾虚热在下焦，淡渗导损阳气，阴无以化。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 大尹刘天锡 | 内有湿热，大便滑利，小便涩滞，服淡渗愈加滴沥，小腹腿膝皆肿，两眼胀痛 | 地黄、滋肾二丸 → 补中益气加麦门、五味 | 小便如故 → 而愈 |
| 州守王用之 | 肚腹膨胀，服二陈枳实、淡渗破气致手足俱冷 → 足三阴虚寒 | 金匮肾气丸 | 不月而康 |
| 州同刘禹功 | 屡用消导、化痰降火、分利、清气化痰，致肚腹胀大、脐突出、不能寝卧，六脉微细 → 命门火衰危症 | 金匮加减肾气丸料（肉桂、附各一钱五分）→ 补中益气送二神丸 → 前药 + 附子贴腰脐涌泉 | 二剂下瘀秽甚多 → 诸症退五六 → 寸脉渐复而安；后惑人言服沉香化气丸，下血，**辞不治** |
| 一富商 | 大便干结常服润肠丸，后胸腹不利、小便滴沥、腹胀少食，服五苓瞿麦致小便不通、体肿喘嗽 | 金匮肾气丸、补中益气汤 | 而愈 |
| 一儒者 | 饮食难化，屡用行气消导、行气化痰、行气分利，致咳嗽喘促、肚腹渐胀、两足浮肿，脉浮大按之微细 | 朝补中益气加姜、附；夕金匮肾气加骨脂、肉果 → 八味丸 → 补中、八味 | 诸症渐愈 → 两月能步履 → 半载而康 |
| 一男子 | 唾痰口干，屡用化痰行气、导痰理脾、分气利水、破血消导，致腹大胁痛、两足皆肿 | 朝金匮加减肾气丸，夕补中益气煎送前丸 → 八味丸、补中汤 → 大补汤、还少丹 | 月余渐退 → 两月能步履 → 半载而康 |
| 一男子 | 患前症，壮火补土渐愈，彼欲速，服攻积之剂下血甚多 → 阴络伤 | （辞） | **后果殁** |
| 一男子 | 胸膈痞闷，专服破气之药 → 血虚之病，血生于脾土 | （彼不信，又用内伤之药） | 反吐血 → **阳络伤**，后果殁 |
| 沈大方之妻赵氏 | 痰热屡进寒凉三四年，遍身浮肿，手足麻冷，日夜咳嗽，烦躁引饮，小水不利，大肉尽去，脉洪大无伦按之如无 → 虚热无火 | 金匮肾气丸料 → 日服前丸及大补之药 → 八味丸、金匮肾气丸料加参〔芪〕归术 → 加黄连吴茱木香 → 补中益气加木香黄连吴茱五味 | 顿觉小水溃决如泉，二十余剂而愈；三年后复作，逾月而起 |

末案附沈大方长跋，是全书篇幅最长的一篇患者家属来书。

**本症所见规则**：#17 无火无水｜#22 误攻致络伤（阴络／阳络）｜#12 转归照实记

## 症四 · 脾胃亏损暑湿所伤等症（7 案，附「食生冷入房」）

**主轴**：暑湿不是单独一类病，他仍按脾虚寒湿处理；黄胆、蓄血则用**攻法**——并不一味补。

> 「有是病而用是药。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 大司徒李蒲汀 | 患黄胆，当用淡渗之剂，因尚无嗣犹豫 | 茵陈五苓散加芩、连、山栀 | 二剂而愈（后得子） |
| 应天王治中 | 遍身发黄，妄言如狂，胸痛手不可近 → 中焦蓄血 | 桃仁承气汤 | 一剂下瘀血而愈 |
| 太守朱阳山弟 | 下部蓄血发狂 | 抵当汤 | 而愈 |
| 一儒者 | 每春夏口干发热，劳则头痛，服清凉化痰致泻喘烦躁，用香薷饮致神思昏愦 → 闭藏之际不远帏幕，名曰注夏 | 补中益气去柴胡、升麻，加五味、麦门、炮姜 → 加肉桂五分 → 六味丸 | 一剂脉益甚 → 服之即苏 → 而痊 |
| 一儒者 | 体肥善饮，仲秋痰喘，用二陈芩连益甚，加桑皮杏仁致盗汗气促，加贝母枳壳致不时发热 → 脾肺虚寒 | 八味丸补土母 + 补中益气接中气 | 而愈 |
| 一男子 | 夏月入房，食冰果腹痛 | 附子理中汤 | 而愈（同患者不信，用二陈芩连**而死**） |
| 一男子 | 盛暑发热，胸背作痛，饮汤自汗，用发表药致昏愦谵语、大便不实、吐痰甚多 | 十全大补 → 补中益气加炮姜 | 一剂顿退 → 二剂痊愈 |

## 症五 · 肝脾肾亏损头目耳鼻等症（11 案）

**主轴**：目赤、耳鸣他不治耳目，先看脾胃与肾水。引东垣一段作纲：

> 「脾虚则五脏之精气皆为失所，若不理脾胃，不养神血，乃治标而不治本也。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 给事张禹功 | 目赤不明，服祛风散热反畏明重听，脉大而虚 → 劳心过度，饮食失节 | 补中益气加茯神、枣仁、山药、山茱、五味 → 十全大补兼前药 → 补中益气加前药 | 顿愈 → 渐愈 → 而痊 |
| 少宰李蒲汀 | 耳如蝉鸣，服四物耳鸣益甚 → 元气亏损 | 五更六味地黄丸，食前补中益气汤 | 顿愈 |
| 少司马黎仰之 | 因怒耳鸣，吐痰作呕不食，寒热胁痛 | 小柴胡合四物加山栀、茯神、陈皮 | 而瘥 |
| 尚宝刘毅斋 | 怒则太阳作痛 | 小柴胡加茯苓、山栀 → 六味丸 | 后不再发 |
| 一儒者 | 日晡两目紧涩不能瞻视 → 元气下陷 | 补中益气倍加参〔芪〕 | 数剂痊愈 |
| 一男子 | 同前症，服柏知更加便血 → 脾不统血，肝不藏血 | 补中益气、六味地黄 | 而愈 |
| 一儒者 | 两目作痛，服降火祛风致两目如绯、热倦殊甚 | 十全大补汤 → 补中益气兼六味丸 → 十全大补 | 诸症悉退 → 而愈 → 而痊 |
| 一男子 | 房劳兼怒，风府胀闷，两胁胀痛 → 色欲损肾，怒气伤肝 | 六味地黄丸料加柴胡、当归 | 一剂而安 |
| 一儒者 | 酒色过度，头脑两胁作痛 → 肾虚而肝病 | 同上 | 顿安 |
| 一男子 | 面白鼻流清涕，不闻馨秽三年 | 补中益气加麦门、山栀 | 而愈 |
| 一男子（二十） | 素嗜酒色，两目赤痛，两尺洪大按之微弱 → 断「目当失明」 | 六味地黄料加麦门、五味 | 翌早果然失明，一剂顿明 |

末案是全书中**预判最准的一例**——先断失明，次日即应，再一剂复明。

**本症所见规则**：#18 滋化源｜#24 治未病

## 症六 · 脾肺肾亏损小便自遗淋涩等症（11 案）

**主轴**：小便病他先分「阴无以化」与「阳无以生」，再按脏腑定位。这一症给了一张**分级用方表**（原文一段十二个「若」），是全书中体例最接近"诊疗路径"的文字。

> 「若转筋小便不通，或喘急欲死，不问男女孕妇，急用八味丸，缓则不救。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 大司徒许函谷 | 因劳发热，小便自遗或时不利 → 肝火阴挺不能约制 | 午前补中益气加山药、黄柏、知母；午后地黄丸 | 月余诸症悉退 |
| 司徒边华泉 | 小便频数，涩滞短赤，口干唾痰 → 肾经阳虚热燥 | 六味、滋肾二丸 | 而愈 |
| 司马李梧山 | 茎中作痛，小便如淋，口干唾痰 → 思色精降而内败 | 补中益气、六味地黄 | 而愈 |
| 考功杨村庵 | 口舌干燥，小便频数 → 膀胱阳燥阴虚 | 滋肾丸 → 补中益气、六味地黄 | 小便愈 → 而安 |
| 司空何燕泉 | 小便赤短，体倦食少，缺盆作痛 → 脾肺虚弱不能生肾水 | 补中益气、六味丸加五味 | 而安 |
| 商主客 | 素膏粱，小便赤数，吐痰稠粘，右寸关数而有力 → 脾肺积热遗于膀胱 | 黄芩清肺饮 → 滋肾、六味二丸 | 而愈 |
| 一儒者 | 发热无时，饮水不绝，小便涩痛，大便牵痛 → 精竭复耗 | 六味丸加五味子 + 补中益气 | 得愈 |
| 儒者杨文魁 | 痢后两足浮肿，胸腹胀满，小便短少，用分利致遍身肿兼气喘 | 补中益气汤加附子 | 而愈（半载后复作，仍服前药顿愈） |
| 余自述（甲戌年） | 劳役过甚，兼怒气，次年春茎中作痒、时出白津 | 地黄丸及补中益气加黄柏、柴胡、山栀、茯苓、木通 | 而愈（丁酉复作，加木通、茯苓、胆草、泽泻） |
| 大尹顾荣甫 | 尾闾作痒，小便赤涩，左尺洪数 → 肾经虚热；服柏知年许致高骨肿痛 | （断子母俱败） | **后果殁** |
| 顾同崖 | 左尺涩结，右寸洪数 → 肺金不能生肾水 | （预言） | 至季冬茎道涩痛**而殁** |

**本症所见规则**：#17 无火无水｜#32 分级用方表｜#24 断死期

## 症七 · 脾肺肾亏损虚劳怯弱等症（8 案）

**主轴**：虚劳他按「金水俱虚→滋化源」处理，并记了一个**少年早婚**的完整病程。

> 「此金水俱虚之症，兼服地黄丸而愈。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 庶吉士黄伯邻 | 发热吐痰，口干体倦，自用补中益气不应 → 金水俱虚 | 补中益气 + 地黄丸 | 而愈（后患疖，用地黄丸料煎服即退） |
| 少司空何潇用 | 足热口干，吐痰头晕，服四物、黄连、黄柏致饮食即减、痰热益甚 | 十全大补加麦门、五味、山药、山茱 | 而愈 |
| 一儒者 | 两足发热，或脚跟作痛 | 六味丸及四物加麦门、五味、玄参 → 当归补血汤 | 而愈 → 而安 |
| 儒者刘允功 | 形体魁伟，冬日饮水，自喜壮实 → 断「此阴虚也」 | 六味地黄、补中益气 | 而愈 |
| 一男子 | 腿内作痛，用渗湿化痰致痛连臀肉、面赤吐痰、脚跟发热 → 肾虚阴火上炎 | （不信，服柏知） | **而殁** |
| 余甥居宏（十四娶，二十发病） | 发热作渴，面赤作胀，外砭血内降火，痰涎愈多，脉洪数鼓指 | 六味丸及大补汤加麦门、五味 | 而痊 |
| 余甥凌云汉（十六） | 作渴发热，吐痰唇燥，遍身生疥，两腿尤多，日晡愈炽，冬患疮，尺脉洪数 → 疥属肾疳，疮属骨疽 | 六味地黄、十全大补 → 针之脓出 | 二旬诸症愈而瘵症具，仍用前药而愈；娶妻后复作，服地黄丸数斤、煎药三百余剂而愈 |
| 其弟云霄（十五） | 面赤唇燥，形体消瘦；逐年观察至「胃经部分有青色」→ 木乘土 | 六君加柴胡、芍药、山栀、芜荑、炒黑黄连 → 四味肥儿、六味地黄 → 加胆草柴胡 → 去芍加肉桂 → 加减八味丸 | 肝火渐退，元气渐复而愈 |

云霄案是全书唯一**连续四年只观察不处方**的记录（壬寅见→癸卯「病愈深矣」→甲辰见青色始治）。

**本症所见规则**：#28 少年阴虚之辨｜#24 治未病

## 症八 · 脾肺肾亏损遗精吐血便血等症（16 案）

**主轴**：血证与精证同源——「脾统血，肺主气」。

> 「脾统血，肺主气，此劳伤脾肺，致血妄行，故用前药健脾肺之气，而嘘血归源耳。」

## 症九 · 肝脾肾亏损下部疮肿等症（4 案）

**主轴**：腿足生疮，久不收口，他判**肾虚**而非疮毒。

> 「此等症候，用祛风败毒之剂，以致误人多矣。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 通府黄廷用 | 两足发热，口干吐痰，服二陈四物益甚，足跟热痒误作疮毒，敷药破而出水，追毒丹后疮突如桃 | 滋其化源（补中益气、六味地黄一路） | 半载得瘥 |
| 儒者章立之 | 左股作痛，用清热渗湿致色赤肿胀、痛连腰胁、腿足无力 → 足三阴虚 | 补中益气、六味地黄 | 两月余元气渐复，年许而痊 |
| 府痒钟之英 | 两腿生疮，色黯如钱，似癣三四，痒痛相循，脓水淋漓，晡热口干面黧 → 肾虚 | 加味六味丸 | 数日而愈 |
| 一男子 | 素遗精，足跟作痛，口干作渴，大便干燥，午后热甚 | 补中益气加芍药、玄参 + 六味丸 | 而愈 |

**本症所见规则**：#31 疮疡内治｜#2 苦寒／败毒禁区

## 症十 · 脾肺肾亏损大便秘结等症（7 案）

**主轴**：便秘他分六路，且**反对通下**——燥在直肠才用导法。

> 「若燥在直肠，用猪胆汁导之。……若复伤胃气，多成败症。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 一儒者 | 大便素结，服搜风顺气丸后胸膈不利、饮食善消、面赤，左关尺洪而虚 → 足三阴虚；又服润肠丸致大便不实 | 补中益气、六味地黄汤 | 月余而验，年许而安 |
| 一老儒 | 素有风热，大便十七日不通，肚腹不胀，脉洪大而虚 → 阴火烁津液 | 六味丸二十余剂 → 猪胆润导 | 至三十二日始欲去，通利如常 |
| 一妇人（七十三） | 痰喘内热，大便不通，两月不寐，脉洪大重按微细 → 肝肺肾亏损 | 朝六味丸，夕逍遥散各三十余剂 → 猪胆汁导 → 十全大补 | 腹始痞闷 → 通 → 而安 |
| 一男子（五十余） | 因怒少食，大便不利，服润肠丸、脾约丸致胸胁作痛，肝脾肾脉浮而涩 → 足三阴精血亏损 | 滋其化源 | 果验 |
| 一儒者 | 怀抱郁结，场屋不遂，服清热化痰行气益甚，心脾二脉涩滞 → 郁结伤脾 | 加味归脾汤 → 八珍汤加苁蓉、麦门、五味 | 饮食渐进，大便尚涩 → 三十余剂自润 |
| 一男子 | 同前，不信，服大黄致泄泻便血、遍身黑黯 → 阴阳二络俱伤 | （辞不治） | **后果然** |
