## 症一 · 元气亏损内伤外感等症（25 案）

**主轴**：同一个「口眼斜、半身不遂」，他不当一个病名治，而先分三层——真气虚而风邪所乘、手足阳明经虚而风寒所乘、脾虚湿热。名同而机异，故方亦三路。

> 「此真气虚而风邪所乘，以三生饮一两，加人参一两，煎服即苏。」

**本症最重的一段**，是对"服搜风、天麻二丸以预防中风"的批评：

> 「愚谓预防之理，当养气血，节饮食，戒七情，远帏幕可也。若服前丸以预防，适所以招风取中也。」

| 车驾王用之 | 卒中昏愦，口眼斜，痰气上涌，六脉沉伏 → 真气虚风邪所乘 | 三生饮一两加人参一两 | 煎服即苏 |
| 州判蒋大用 | 中满吐痰，劳则头晕，指麻 → 脾气亏损／不运／不升／不周 | 补中益气加茯苓、半夏；八味地黄补土母 | 而愈（后自服搜风、天麻丸，大便不禁，饮食不进，殁） |
| 一男子 | 卒中口眼斜，不能言语，遇风寒四肢拘急，脉浮而紧 → 手足阳明经虚 | 秦艽升麻汤 → 补中益气加山栀 | 稍愈 → 而痊 |

| 一男子 | 善饮，舌本强硬，语言不清 → 脾虚湿热 | 补中益气加神曲、麦芽、干葛、泽泻 | 未见记录（只出方议） |
| 一妇人 | 善怒，舌本强，手臂麻 → 舌本属土，被木克制 | 六君加柴胡、芍药 | 未见记录 |
| 一男子 | 舌下牵强，手大指次指不仁，或便秘，或皮肤赤晕 → 大肠血虚风热 | 逍遥散加槐角、秦艽 | 未见记录 |
| 一男子 | 足痿软，日晡热 → 足三阴虚 | 六味、滋肾二丸 | 未见记录 |
| 一妇人 | 腿足无力，劳则倦怠 → 四肢属脾 | 补中益气及还少丹 | 未见记录 |

**卷末一句是全症最重的**：

> 「俱不从余言，各执搜风、天麻二丸并愈风丹而殒。」

末五案他不写疗效，只写处方——因为病人没服药。这一句把"未见记录"与「殁」的分别写清楚了。

## 症二 · 饮食劳倦亏损元气等症（14 案）

**主轴**：一切「火症」在此症下都被他判为**无根虚火**，治法只有一条——固其根本。

> 「皆是无根虚火，但服前汤固其根本，诸症自息，若攻其风热则误矣。」

> 「凡人饮食劳役起居失宜，见一切火症，悉属内真寒而外假热。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 进士王汝和 | 劳役后忽然昏愦 → 元气虚火妄动，挟痰而作 | 先灌童便 → 参〔芪〕芎归玄参柴胡山栀炙草 → 十全大补加五味、麦门 | 神思渐爽 → 而安 |
| 光禄高署丞 | 脾胃素虚，饮食劳倦腹痛胸痞，误用大黄下之，谵语烦躁、喘汗吐泻、脉大无伦次 | 六君子加炮姜四剂 | 而安（后倦怠少食，仍补胃而退） |
| 大尹徐克明 | 饮食失宜，日晡发热，自用四物柏知→头眩目赤；芩连枳实→汗出如水；二陈柏知麦味→言语谵妄、两手举拂 | 参〔芪〕归术远志茯神枣仁炙草 → 八珍汤 | 熟睡良久，四剂稍安 → 而愈 |
| 一男子 | 每遇劳役食少胸痞、发热头痛、脉浮大 → 脾胃血虚（阴虚即脾虚） | 六君加炮姜 → 补中益气 | 痛呕渐愈 → 痊愈 |
| 秀才刘贯卿 | 劳役失节，误用人参败毒散致痰喘昏愦、胸间发斑如蚊呐 | 补中益气加姜、桂、麦门、五味 | 而愈 |
| 黄武选 | 饮食劳倦发热恶寒，解表益甚，再剂昏愦，胸发黑斑，脉洪数无力 | 欲用补中益气 | **不从而殁** |
| 一儒者 | 饮食失节，大便下血或赤或黯，半载后非便血则盗汗、非恶寒则发热，六脉浮大 | 午前归脾加麦门、五味 | 收耗散之液（后文有阙） |
| 儒者许梅村亲（马生） | 发热烦渴，服发散药反加喘急腹痛、汗如水、昼夜谵语 → 劳伤元气误汗 | 十全大补加附子一钱 | 熟睡，觉而诸症顿退，再剂而痊 |
| 一儒者 | 日晡两目紧涩不能瞻视 → 元气下陷 | 补中益气倍加参〔芪〕 | 数剂痊愈 |
| 一男子 | 同前症，服柏知致目疾益甚、更加便血 → 脾不统血，肝不藏血 | 补中益气、六味地黄 | 诸症渐愈 |
| 一男子（销银匠） | 饮食劳倦发寒热，右手麻木，误作疔毒敷寒凉，肿胀重坠，六脉浮大按之如无 | 补中益气及温和之药煎渍汤手 | 而愈 |
| 一儒者 | 修左足伤大指甲少许，后因饮食劳倦足重坠肿痛，误服败毒致寒热肿痛 → 脾气虚弱下陷 | 十全大补汤 | 而愈 |
| 余自述（观书久坐） | 倦怠、夜少寐、足内酸热、腿筋抽缩 → 劳伤元气，阴火乘虚下注 | 补中益气加麦门、五味、酒炒黑黄柏少许 | 精神清妥 |

## 症三 · 脾胃亏损心腹作痛等症（7 案）

**主轴**：痛证他先看**面色**——「黄中见青」即脾虚肝乘。并直接否掉「痛无补法」。

> 「向使泥其痛无补法，而反用攻伐之药，祸不旋踵。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 唐仪部 | 胸内作痛月余，腹亦痛，左关弦长、右关弦紧 → 脾虚肝邪所乘（面色黄中见青） | 补中益气加半夏、木香 → 六君子汤 | 二剂而愈 → 二剂而安 |
| 仪部李北川 | 常患腹痛，因怒加剧，胸胁作胀，呕吐不食，肝脉弦紧（黄中见青兼赤） | 补中益气吞左金丸 | 一服而愈 |
| 太守朱阳山 | 因怒腹痛作泻，两胁胀，寒热往来，呕吐痰涎，神思不清 → 肝木乘脾土 | 小柴胡加山栀、炮姜、茯苓、陈皮、制黄连 | 一剂而愈 |
| 朱阳山之内 | 素善怒，胸膈不利，吐痰多，吞酸嗳腐十余年，左关弦洪、右关弦数 → 肝火血燥，木乘土位 | 朝六味地黄丸，夕六君加当归、芍药 | 不月而愈（后大怒复作，六君加姜桂一钟即睡） |
| 儒者沈尼文 | 内停饮食，外感风寒，头痛发热，恶心腹痛；次日复作，重按痛止 → 客寒乘虚 | 人参养胃汤加芎、芷、曲、柏、香附、桔梗 → 香砂六君加木香、炮姜 → 去二香，加黄〔芪〕当归少佐升麻 | 一剂而愈 → 痛减六七 → 而愈 |

| 一妇人 | 怀抱郁结，不时心腹作痛，年余不愈，诸药不应 | 归脾加炒山栀 | 而愈 |

## 症四 · 脾肾虚寒阳气脱陷等症（6 案，含一则完整救逆记录）

**主轴**：阳气脱陷时，**药不能下**怎么办——他改用外治。

> 「急用盐附子炒热熨脐腹，以散寒回阳；又以口气补接母口之气；又以附子作饼，热贴脐间。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 谭侍御 | 但头痛即吐清水，不拘冬夏，吃姜便止，已三年 → 中气虚寒 | 六君加当归、黄〔芪〕、木香、炮姜 | 而瘥 |
| 一儒者 | 四时喜极热饮食，吞酸嗳腐，大便不实，足指缝湿痒 → 脾气虚寒下陷 | 六君加姜、桂 → 加附子钱许 | 而愈 → 数剂不再发 |
| 一男子 | 形体倦怠，足指缝湿痒，行坐久则重坠 → 脾胃气虚下陷 | 补中益气加茯苓、半夏 | 而愈 |
| 一男子 | 食少胸满，手足逆冷，畏寒发热吐痰，自用清化、二陈、枳实、四苓、柏知致小便淋漓 | 八味丸补火生土 + 补中益气加姜、桂 | 寻愈 |
| 一男子 | 每劳肢体时痛，误用清痰理气、导湿致臂痛漫肿、内热盗汗，脉浮大按之微细 → 阳气虚寒 | 补中益气加附子一钱、人参五钱 → 十全大补百余剂 | 肿痛悉愈 → 而康（计服过人参一十三斤，姜附各斤余） |

## 症五 · 命门火衰不能生土等症（8 案）

**主轴**：脾胃久治不效，他改从**命门**治——「补土之母」。这是他最有名的一条路径，也是被讥"执泥补法"的由来。

> 「此非脾胃病，乃命门火衰不能生土，土虚寒使之然也，若专主脾胃，误矣。」

| 患者 | 证 / 他的判断 | 方 | 效 |
|---|---|---|---|
| 廷评张汝翰 | 胸膈作痞，饮食难化，服枳术丸致形体消瘦、发热口干，脉浮大而微 | 补中益气加姜、桂 → 八味丸 | 诸症悉退 → 不月饮食进，三月形体充 |
| 一儒者 | 盛暑喜燃火，四肢欲沸汤渍，面赤吐痰似实火，惟食椒姜方快 → 食入反出，脾胃虚寒 | 八味丸及十全大补加炮姜 | 渐愈，不月平复 |
| 一妇人 | 饮食无过碗许，大便不实或吞酸嗳腐，服二陈、黄连加内热作呕 → 脾胃虚弱，末传寒中 | 六君加炮姜、木香 → 补中益气加炮姜、木香、茯苓、半夏 | 胃气渐复 → 痊愈（后怒复作，益气汤八味丸两月悉愈） |
| 朱佐（自述） | 失足后左足麻木，夏月足寒如冰；醉后饮水致右腹痞结，摩之有声，饮食稍多则痛泻，服枳术丸不效 | 八味丸 | 果验 |
