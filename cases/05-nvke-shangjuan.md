## 一、经候不调（25 条）

**论**（全篇最有价值的一段，直接可当分证表）：

> 「若先期而至者，有因脾经血燥，有因脾经郁滞，有因肝经怒火，有因血分有热，有因劳役火动；其过期而至者，有因脾经血虚，有因肝经血少，有因气虚血弱。」

| 证 | 方 |
|---|---|
| 脾经血燥 | 加味逍遥散 |
| 脾经郁滞 | 归脾汤 |
| 肝经怒火 | 加味小柴胡汤 |
| 血分有热 | 加味四物汤 |
| 劳役火动 | 补中益气汤 |
| 脾经血虚 | 人参养荣汤 |
| 肝经血少 | 六味地黄丸 |
| 气虚血弱 | 八珍汤 |

并给四句口诀：肝脾血燥四物为主、肝脾血弱补中益气为主、肝脾郁结归脾为主、肝经怒火加味逍遥为主。

## 二、经漏不止（11 条）

**论**：

> 「其为患因脾胃虚损，不能摄血归源；或因肝经有火，血得热而下行；或因肝经有风，血得风而妄行；或因怒动肝火，血热而沸腾；或因脾经郁结，血伤而不归经；或因悲哀太过，胞络伤而下崩。」

| 证 | 方 |
|---|---|
| 脾胃虚弱 | 六君加当归川芎柴胡 |
| 脾胃虚陷 | 补中益气加酒炒芍药、山栀 |
| 肝经血热 | 四物加柴胡山栀苓术 |
| 肝经怒火 | 小柴胡加山栀芍药丹皮 |
| 脾经郁火 | 归脾加山栀柴胡丹皮 |
| 哀伤胞络 | 四君加柴胡升麻山栀 |

并有一句极重的告诫：

> 「若大吐血后，毋以脉诊，当急用独参汤救之。」

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人（近七十） | 素有肝脾症，作则不食、胸膈不利、中脘痛、便泻 → 后忧女孀居吐紫血 → 后大怒吐赤血甚多、躁渴垂死，血脱 | 逍遥加山栀茯神远志木香 → 加炒黑黄连吴茱 → 人参一两，苓术当归各三钱，陈皮炮黑干姜各二钱，炙草木香各一钱 | 顿愈；「一剂顿止」 |
| 一妇人（六十四） | 久郁怒、乳内时痛、有血如经行、大惊恐 → 肝脾郁火血燥 | 逍遥加酒炒黑龙胆、山栀 → 归脾加炒栀贝母 | 四剂全消；诸症悉愈 |
| 一妇人 | 久患血崩、肢体消瘦、闻食腥臊 → 血枯，肺肝脾胃亏损 | 八珍汤、乌贼鱼骨圆 | 两月经行，百余剂康宁 |
| 一妇人 | 性躁急、瘰后吐血发热、两胁胀痛 → 怒气伤肝，气血俱虚 | 朝逍遥倍加炒黑山栀黄柏贝母桔梗麦味；夕归脾汤送地黄丸 | 诸症并愈 |

| 一女子 | 素郁结、胸满食少、吐血面赤 | 地黄丸及归脾加山栀贝母芍药 | 而愈 |
| 一妇人 | 面黄或赤、腰脐下痛、经行先寒热、血如崩 → 脾胃亏损，元气下陷，相火湿热 | 补中益气加防风芍药炒黑黄柏，间以归脾 | 血自归经 |
| 一妇人 | 因怒崩血久不已、面青黄或赤 → 肝木制脾土而血虚 | 小柴胡合四物 → 归脾、补中二汤 | 而瘥 |

## 三、经闭不行（8 条）

**论**：把经闭拆成八因——脾虚不生血、脾郁耗血、胃火消烁、脾胃损血少、劳伤心血少、怒伤肝血少、肾不生肝、肺气虚不能行血。治则一句最要紧：

> 「损其肺者益其气，损其心者调其荣卫，损其脾者调其饮食，适其寒温，损其肝者缓其中，损其肾者益其精。」

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 停食饱闷发热，屡用参养胃、木香槟榔丸、二陈连朴致腹胀经不至 → 中气亏损 | 补中益气加茯苓半夏 | 三十余剂诸症愈；二十余剂经自行 |
| 一妇人 | 食后腹胀吞酸，服枳术丸益甚、腿肿经不行 → 郁结伤脾，脾虚湿热下注 | 侵晨四君芎归二陈；午后前汤送越鞠丸 → 归脾、八珍 | 渐愈；两月余经行 |
| 一妇人 | 性沉多虑、经不行、胸满少食 → 中气虚寒 | 补中益气加砂仁香附煨姜 → 六君加芎归贝母桔梗姜枣 | 胸膈和；经自调 |
| 一妇人 | 素有胃火，服清胃散而安；后劳役致经不行 → 胃火消烁阴血 | 逍遥加丹皮炒栀 + 八珍加茯苓远志 | 经自行 |
| 一妇人 | 久患疟、形怯、内热晡热、服通经丸虚症悉具 → 因虚致疟，因疟致闭 | 补中益气及六味地黄丸各百余剂 | 疟愈经自行 |
| 一妇人 | 久疟、疟作则经不行、形虚脉大、元气下陷相火合病 | 补中益气 → 加蔓荆子 → 六味地黄丸 | 寻愈；经行 |
| 一妇人 | 因劳耳鸣头痛体倦 → 元气不足；三年后得子又因劳经不行 | 补中益气加麦味 → 六味地黄丸、补中益气 | 而痊 → 顿愈 |
| 一妇人 | 胃气素弱、哭母吐血咳嗽、经三月不行 → 悲伤肺，思伤脾 | 朝补中益气加桔梗贝母知母；夕归脾汤送地黄丸 | 而愈 |

## 四、带下（8 条）

## 五、血分水分（2 条）

**论**：先经断后浮肿、小便不通者，**血化为水**，名血分，椒仁丸；先小便不利后身面浮肿、经不通者，**水化为血**，名水分，葶苈丸。

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 经不调、肌瘦、小便频数，服济阴丸致四肢浮肿、小便不通 → 血分 | 朝椒仁丸，夕归脾汤 → 人参丸 → 归脾汤五十余剂 | 渐愈；而痊 |
| 一妇人 | 经不调、小便短少，服清热分利致身面浮肿、经不通 → 水分 | 朝葶苈丸，夕归脾汤 → 人参丸间服 | 而愈 |

原注一句很重：「已上二症，作脾虚水气，用分利等药而殁者多矣。惜哉!」

## 六、小便出血（2 条）

**论**：怒动肝火→加味逍遥送发灰；肝经风热→子芩丸；久血虚→八珍送发灰；膏粱积热→清胃散加槐花甘草；房劳→六君加柴胡升麻；风热→四君加防风枳壳；久亏损元气→补中益气；郁结伤脾→济生归脾。

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 尿血、因怒寒热头痛胁胀 → 后郁怒小腹痛、尿血热甚 | 加味逍遥 → 补中益气加蔓荆子 → 前散加龙胆草并归脾汤 | 稍愈；而痊（后因饮食伤复作，用前汤而痊） |

## 七、热入血室（3 条）

**论**：昼明了安静、夜谵语如见鬼状，小柴胡加生地黄；血虚者四物加生地柴胡。**「切不可犯胃气」**。

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 经行感冒、日安静夜谵语 | 小柴胡加生地 → 补中益气加蔓荆子 → 加味逍遥加生地 | 顿安；而愈 |
| 一妇人 | 因怒寒热谵语、经暴至 → 怒动火而血妄行 | 加味逍遥散加生地 → 补中益气 | 神思顿清；月经渐止 |
| 一妇人 | 怀抱素郁、经行谵语，发散不应、寒凉益甚、经不止 → 脾胃虚寒 | 香砂六君 → 归脾汤 | 诸症渐退；痊愈 |

## 八、师尼寡妇寒热（6 条）

**论**：引褚氏「独阴无阳，致血气交争」之说，主小柴胡加生地；久血虚佐四物；怒动肝火佐加味逍遥；亏损肝经佐八珍；亏损元气佐补中益气；郁伤脾气佐济生归脾。

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一寡妇 | 因怒不时寒热、肝脉弦紧 | 小柴胡加生地 → 加味归脾、补中益气 | 而愈；兼服而止 |
| 一妇人 | 夫经商久不归、发寒热、经旬日方止，服降火凉血反潮热盗汗、经频数 → 热汗气血虚，经频肝脾虚 | 归脾汤、六味丸 | 而愈 |
| 一室女 | 寒热、左手脉弦长而出寸口 | 小柴胡加生地乌梅 | 而愈；既嫁诸症悉痊 |
| 一室女 | 久患寒热、经不调 | 小柴胡加生地 → 生地黄丸 | 少愈；而痊 |

## 九、历节痛风（6 条）

**论**：分风邪（小续命汤）、走注（漏芦散）、骨节痛（四生丸）、湿热（清燥汤）、肝火（加味逍遥加羌活川芎）、脾郁（加味归脾加羌活川芎）、血虚（四物加羌活川芎）、气虚（四君加）、气血俱虚（八珍加）。并给一组判断：

> 「大抵痛而不敢按者，属病气元气俱实也；手按而痛缓者，病气元气俱虚也。」

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 自汗盗汗、体倦少食、经不调、遍身痛、天阴益甚，二年 | 小续命汤 → 补中益气、加味归脾三十余剂 | 痛止；而愈 |
| 一妇人 | 因怒经多、发热作渴、左目紧小、四肢抽搐、遍身痛 → 怒动肝火，血虚生风 | 加味逍遥加钩藤 → 八珍汤 | 渐愈；而痊 |
| 一妇人 | 经先期、素有痛症、重按稍止 → 气血虚而有火 | 十全大补加独活 → 六味丸、逍遥散 | 痛痊；经调 |
| 一妇人 | 历节痛、发热作渴、经过期、脉洪大按之微细 | 附子八物四剂 → 加味逍遥、六味丸 | 痛止；经调 |
| 一妇人体肥 | 素内热、经先期、痛风下体肿痛、脉缓 → 风湿而血虚有热 | 羌活胜湿汤 → 清燥汤 → 加味逍遥 → 六君加柴胡升麻 → 补中益气 | 逐步而愈（中途多次因怒／食复） |
| 一妇人 | 食少畏风寒、痛风呕吐寒热、脉弦紧 | 附子八物、独活寄生、大防风 → 加味归脾、逍遥 | 痛愈；肿消；元气复 |

## 十、流注（6 条）

**论**：皆属虚损，「急用葱熨及益气养荣汤，则未成自消，已成自溃」。并列出八种虚象对应方（八珍、十全大补、四物加参术、六君加炮姜、补中益气加苓夏、八味丸、六味丸、八珍加柴胡丹皮）。**「若不补气血……或用寒凉克伐，俱不治。」**

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 左臂患之年许不溃、坚硬不痛、脉弱少食、日晡热 | 参〔芪〕归术川芎芍药熟地贝母远志香附桔梗丹皮甘草 | 百余贴而消 |
| 一妇人 | 暴怒腰肿一块、气走作痛 | 方脉流气饮 → 小柴胡对四物加香附贝母 | 数剂止；月余愈 |
| 一妇人 | 因怒胁下肿痛、脉沉滞 | 方脉流气饮 → 小柴胡对二陈加青皮桔梗贝母 → 小柴胡对四物 | 顿退；而痊 |
| 一妇人 | 闪胸肩患肿、遍身痛 | 黑丸子 → 方脉流气饮 → 二陈对四物加香附枳壳桔梗 | 而痊愈 |
| 一妇人 | 腿患筋挛骨痛、脉迟紧 | 大防风汤 | 二剂顿退，又二剂而安（另一妇同法加黑丸子） |
| 一妇人 | 溃后发热，他医作虚不信，服败毒药 | （患者服败毒） | **发大热，竟至不救** |

## 十一、瘰（6 条）

**论**：多生于耳前后、项侧、胸胁；寒热肿痛者肝经气动（柴胡栀子散为主，佐逍遥养肝血）；核不消者肝血亦病（加味四物为主）。**「切不可轻用散坚追毒之剂」**；久溃脉浮大、色白者皆不治。

| 患者 | 判 | 方 | 效 |
|---|---|---|---|
| 一妇人 | 久不愈，用散肿溃坚汤伐之肿硬益甚 → 肝经气血亏损，当滋化源 | 六味地黄丸、补中益气汤 | 至春而愈 |
| 一妇人 | 恐不起致少寐、年余破、误服通经丸、午前恶寒午后发热 → 思虑亏损脾血 | 归脾汤作丸；午前六君送下，午后逍遥送下 | 两月得寐；半载经如期；年余疮愈 |
| 一妇 | 溃后发热烦躁、脉大而虚 | 当归补血汤 → 圣愈汤 → 八珍加贝母远志 | 六剂寒热退；而敛 |
| 一妇人 | 项结核、寒热头痛、胁乳胀痛 → 肝火血虚 | 四物加柴胡山栀胆草 → 加味逍遥 | 而愈；而安 |
| 一妇人 | 瘰后遍身作痒、脉大按而虚 | 十全大补加香附 | 而愈（原注：溃后午前痒属气虚，午后痒属血虚；作风症治必死） |
| 一妇人 | 项核肿痛、气血俱实 | 必效散下之 → 益气养荣汤 | 三十余剂而消 |

## 十二、乳痈乳岩（16 条）

**论**：乳痈属胆胃热毒（人参败毒散、神效栝蒌散、加味逍遥）；乳岩属肝脾郁怒、气血亏损（加味归脾、加味逍遥、神效瓜蒌散）。并给一串「以…为主」：

> 「不作脓，或脓不溃，补气血为主。不收敛，或脓稀，补脾胃为主。脓出反痛，或发寒热，补气血为主。」

| 一妇人 | 内热胁胀、两乳时痛、脐下牵痛 → 带脉为患 | 小柴胡加青皮黄连山栀 | 二剂而瘥 |

| 一妇人 | 左乳结核如杏、三月不消、心脉涩脾脉大按之无力 | 八珍加贝母远志香附柴胡青皮桔梗 | 五十余剂而溃，又三十余剂而愈 |

| 一妇人 | 因怒左乳痛发热，表散太过肿热益甚 | 益气养荣汤 → 针脓大泄 → 前汤 | 热止脓成；月余始愈 |

| 一产妇 | 因乳少服药通之致乳房肿胀 | 玉露散 | 而愈 |

## 十五、阴疮（11 条，含阴挺、阴痒、阴虫、交接出血）

| 一妇人 | 素性急、阴中痛、怒则甚 | 芎归炒栀柴胡苓术丹皮泽泻炒芍炒车前炒连生草 → 去黄连泽泻 | 渐愈；而痊 |
